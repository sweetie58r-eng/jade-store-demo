# M2 Visual Acceptance Checklist

Use Cocos Creator 3.8.8 and the same `DemoLayout.scene` setup from `README.md`.

## Checklist

- [ ] The scene still shows the M1 jade, color regions, concentration, cracks, and sample grid.
- [ ] A top-left debug line shows seed, outline point count, color region count, crack count, shape count, placed count, and sample count.
- [ ] A carving palette is visible.
- [ ] The palette includes small bead, cabochon, peace buckle, jade plaque, jade bangle, pixiu, Buddha/Guanyin, jade cabbage, and landscape ornament.
- [ ] The layout starts without default carving instances.
- [ ] Clicking a style in the palette creates one placed carving instance.
- [ ] Clicking the same style repeatedly creates multiple independent instances.
- [ ] Clicking a carving selects it and shows rotation/scale handles.
- [ ] Dragging the body moves the selected carving freely.
- [ ] Dragging the round handle rotates the selected carving continuously.
- [ ] Dragging the square handle scales the selected carving continuously.
- [ ] Mouse wheel scales the selected carving continuously.
- [ ] `Q` and `E` rotate the selected carving by small steps.
- [ ] `Delete` or `Backspace` deletes the selected carving.
- [ ] `R` or the clear button clears all placed carving instances.
- [ ] Green outline indicates valid placement.
- [ ] Yellow outline indicates a shallow-crack warning.
- [ ] Red outline indicates invalid placement.

M2 does not include final price settlement, selling, gallery, ads, login, payment, leaderboards, or backend services.
